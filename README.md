# Кадр

Локальное приложение для записи экрана на Windows: интерфейс HTML в оболочке WinForms/WebView2, запись через MediaRecorder, необязательный FPS-оверлей на базе PresentMon.

[English documentation](README.en.md)

## Требования и запуск

Windows 10 или новее, x64; Microsoft Edge WebView2 Runtime. Запустите `build/installer/Kadr Setup.exe` после сборки. Установщик требует права администратора и при необходимости скачивает WebView2. Для запуска без установки используйте `build/screen-recorder/app/Kadr.exe`, сохранив рядом DLL и папку `ui`.

## Как записывать

1. Выберите режим: экран — до 30 кадров/с, игровой — до 60. Это запрашиваемая, а не гарантированная частота.
2. Выберите звук источника, микрофон, качество и максимальный размер. Настройки сохраняются локально автоматически.
3. Нажмите «Начать запись» и выберите источник в системном диалоге. Доступность звука зависит от выбранного источника и WebView2.
4. Используйте паузу и продолжение; время паузы не входит в таймер. Нажмите «Завершить».
5. Просмотрите и сохраните видео. Удаление несохранённого видео требует подтверждения.

Качество задаёт целевой видеобитрейт: 3, 6 или 12 Мбит/с. Аудио и служебные данные увеличивают итоговый размер. При достижении лимита запись заканчивается; последний фрагмент может немного превысить лимит. Лимит применяется к одной записи, а не ко всей памяти приложения: сохраняйте и удаляйте ненужные записи регулярно.

Записи хранятся в памяти и не восстанавливаются после закрытия или сбоя. В настольном приложении сохранение подтверждается завершением скачивания. При открытии HTML в браузере проверить успешность скачивания автоматически невозможно, поэтому предупреждение о несохранённых записях остаётся.

## Горячие клавиши

| Сочетание | Действие |
| --- | --- |
| Ctrl+Alt+F9 | Начать / завершить запись |
| Ctrl+Alt+F10 | Пауза / продолжение |
| Ctrl+Alt+F11 | Переключить FPS-оверлей для активного окна игры |

Глобальные клавиши доступны в настольном приложении. Для FPS сначала переключитесь на игру; рекомендуется оконный режим без рамки. Сборщик FPS может запросить повышение прав. При конфликте горячих клавиш приложение показывает сообщение.

## Сборка

Нужны Windows x64, Windows PowerShell 5.1 или PowerShell 7, curl.exe, компилятор .NET Framework 4.x и NSIS с поддержкой Unicode. Запустите из корня проекта:

```powershell
./tools/build_kadr.ps1 -MakeNsis 'C:\Program Files (x86)\NSIS\makensis.exe'
```

Скрипт скачивает WebView2 SDK, bootstrapper и PresentMon, проверяет закреплённые SHA-256 и подпись bootstrapper, компилирует C# и создаёт установщик. Интернет требуется при первом скачивании зависимостей. Каталог `build/` исключён из Git. Лицензии сторонних компонентов копируются в приложение; лицензия самого проекта пока не определена.

## Структура

- `screen-recorder/Desktop.cs` — окно, WebView2, сохранение, горячие клавиши.
- `screen-recorder/FpsOverlay.cs` — оверлей, сборщик и расчёт FPS.
- `screen-recorder/Screen Recorder.html` — интерфейс, настройки и запись.
- `screen-recorder/Kadr.nsi` — установка и удаление.
- `tools/build_kadr.ps1` — сборка.

## Ограничения и диагностика

Видео не отправляется на сервер. Настройки и профиль WebView2 сохраняются локально. Для захвата всего экрана живое зеркало отключено, чтобы избежать эффекта бесконечного экрана. Формат выбирается по поддержке среды: обычно WebM, с резервным MP4. Недоступный микрофон не останавливает запись: показывается предупреждение. Эксклюзивный полноэкранный режим игры, DRM и некоторые источники могут не поддерживать захват.

Если запуск не удался, проверьте WebView2 и наличие DLL рядом с EXE. Если нет звука, проверьте разрешение в диалоге выбора источника. Если FPS отсутствует, проверьте выбранное окно игры и разрешение Windows.

## Проверка перед выпуском

Автотестов полного интерфейса пока нет. Проверьте вручную: отмену выбора источника; отказ микрофона; запись с обоими источниками звука; паузу; остановку через системную панель; достижение лимита; воспроизведение; отмену и успешное сохранение; удаление и закрытие с несохранёнными видео; восстановление настроек после перезапуска; горячие клавиши и FPS; установку и удаление на чистой Windows.
